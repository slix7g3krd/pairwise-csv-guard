# pairwise-csv-guard

报表导出支持 CSV 后，公式注入就能从单元格打到运营同事：`=cmd|` 开头的内容被 Excel 执行；`+`、`-`、`@` 开头的值没有被转义；前置制表符和回车能绕过只查首字符的过滤；双引号包裹后公式仍然生效；BOM 和零宽字符让检测失效；分隔符注入能伪造额外列；表头由用户输入，公式进入 header；导出的编码声明错误，客户端按公式解析；单元格换行把一行拆成多行；下载文件名也能注入响应头。security/csv_guard.py 是核心，tests/test_csv_guard.py 15个红。要修的是：危险前缀转义；制表符与回车清理；引号内公式检测；BOM 与零宽字符归一；分隔符转义；表头白名单；编码固定；换行处理；文件名净化；导出前统一编码。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：漏洞检测与攻防；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
